# 卡点侦探 · Campus Gap Diagnoser

面向大学高等数学全课程，以及理论力学、材料力学、结构力学的学习 Skill 开发项目。

## 当前内容

当前仓库保存的是完整的 Skill 创建提示词，尚未生成 Skill 本体、可运行脚本或题库。

打开 [PROMPT.md](PROMPT.md)，将分隔线之后的完整提示词复制到华为云 CodeArts 的技能开发专家中执行。提示词包含产品范围、证据规则、诊断分支、持久化、题库要求、测试、打包与本仓库同步步骤。

## 目标流程

短测定位 → 卡点证据卡 → 定点补习 → 独立迁移题 → 后续复测。

## 目标范围

- 高数：以同济《高等数学》第八版上下册12章为范围基准，学校大纲可覆盖映射；选学内容单列。
- 理论力学：静力学、运动学、动力学及按大纲标明的扩展内容。
- 材料力学：拉压、剪切、扭转、弯曲、应力应变、强度、能量法、稳定等。
- 结构力学：几何组成、静定结构、位移、力法、位移法、力矩分配、影响线、矩阵位移法等；动力、稳定与极限荷载单列扩展。
- 跨课程回溯：根据答题证据区分建模、物理概念、数学计算、单位和边界条件问题，补习后返回专业题复测。

这是创建提示词规定的开发范围，尚不代表已实现。开发后以逐主题覆盖矩阵、实际题库和验证结果报告进度；不把目录存在或题目生成视作教学验证通过。
