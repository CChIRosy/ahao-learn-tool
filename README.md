# 卡点侦探 · Campus Gap Diagnoser

用于大学高数“一元函数求导”的学习 Skill 开发项目。

## 当前内容

当前仓库保存的是完整的 Skill 创建提示词，尚未生成 Skill 本体、可运行脚本或题库。

打开 [PROMPT.md](PROMPT.md)，将分隔线之后的完整提示词复制到华为云 CodeArts 的技能开发专家中执行。提示词包含产品范围、证据规则、诊断分支、持久化、题库要求、测试、打包与本仓库同步步骤。

## 目标流程

短测定位 → 卡点证据卡 → 定点补习 → 独立迁移题 → 后续复测。

计划以约12–15个细分技能、至少60道完成数学核对的题目构建首版。上述数字是开发目标，不是已实现统计。

## 同步目标

- 仓库：`CChIRosy/campus-gap-diagnoser`
- 可见性：私有
- 创建工具执行完成后，将实际 Skill、题库、脚本、测试和验证文档提交到本仓库。

开发产生的真实学习档案、截图、密钥、令牌和报告不得提交；演示路径应标注为合成案例。学习效果需要后续真实试用验证。
