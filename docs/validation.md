# 0.1.0 实际验证记录

日期：2026-11-03。环境：Windows、Python 3.13、SymPy 1.14.0、pytest 9.2.0。下列为本地真实执行结果，不是真实学生研究。

## 已执行

1. `python tools/build_courses.py`：15个数据包，108个主题，540道题。
2. `python tools/validate_resources.py --update`：全部题目ID、题池、前置引用与DAG检查；540个参考答案格式通过；224个参考结果与另写的计算表达式一致；无失败。计算核对与格式检查分别统计。
3. `python -m pytest -q`：49项通过，耗时23.57秒。包括15个模块各一条诊断→补习→迁移→后续复测合成路径，以及求导分支、提示后状态、答题复核、暂停恢复、档案隔离、CLI跨课程返回、安全表达式拒绝、工程单位换算与量纲检查、打包预算。
4. 技能创建工具的`quick_validate.py skill/campus-gap-diagnoser`：`Skill is valid!`。
5. `python tools/build_delivery.py`：ZIP完整性检查通过，包根有SKILL.md，25个文件，解压内容约1MB，低于本项目采用的30文件与40MB约束。精确体积和SHA256见build-stats.json。
6. 将最终ZIP解压到独立临时目录，实际运行课程清单、搜索、创建档案、错误分支、提示记录、报告导出；全部通过。该检查不依赖仓库根目录下的源码路径。

## 修复过的问题

- 题库编写时导数符号与Python字符串引号冲突，已改为正确编码并编译。
- 评分器最初缺少力学变量m，已补充受限变量清单。
- Windows子进程编码需显式UTF-8，已处理。
- 向量与容差匹配也必须保留模型/解释复核，已补充对应测试。
- 展示但未作答的题也加入已见集合，防止重开会话后把已看题当新题。
- 暂停后拒绝提交答案与提示；复核保留提示标记和原始证据。

## 自动测试证明的范围

数据包存在且题池分离、脚本行为满足所测场景、明确的计算核对结果一致、无代码执行式解析。合成模块流程是程序行为验收，不代表所有学生都会获得相同路径，也不代表每道题的教学效果已被验证。
