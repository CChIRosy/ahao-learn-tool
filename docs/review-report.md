本轮完成描述修改和运行修复，保留15个课程模块、108个知识主题、540道原创题。检查覆盖Skill指令、README、演示与质量说明、生成文档、运行反馈和证据卡。

## 语言修改

按反防御性写作规则，先写功能、证据和下一步，把范围与验证状态集中到相应说明中。

|原有表达或行为|本轮修改|
|---|---|
|在多处重复“不代表”“仅提供”等范围说明|开头说明覆盖的课程和知识主题；质量字段与验收状态集中说明|
|答题报告统一提示“本轮证据有限”|按未答、待复核、答错、提示后完成、独立完成分别给出下一步|
|判分宣称“题设定义域下符号结果一致”|改为实际执行的“表达式化简结果一致”|
|解析失败先说“无法可靠自动判分”|直接提示“请按评分要点复核表达式、条件与解题过程”|
|多处重复未设置提醒与教学审核说明|提醒机制在使用步骤说明；教师、学生和宿主验收在质量说明记录|

保留数学条件、单位与模型假设、输入语法、判分复核条件和工程应用范围。这些内容决定答案和使用方式。

## 修复的运行问题

|问题|修复结果|
|公开题目的模型字段包含补习讲解，可能透露答案|改成中性题设说明，回归检查遍历全部诊断题|
|复核旧作答清空已经展示的下一题|保留当前待答题及其ID|
|“不知道”或无效选项被直接判错|记录为待复核，提示确认选择或补充理由|
|待复核作答触发错误回溯|诊断阶段先等待审核，审核后继续|
|连续暂停覆盖恢复阶段，暂停时仍返回题目|连续暂停保持原阶段，恢复回到原题|
|不合格式的context与Windows保留档案名进入后续处理|入口校验并给出格式反馈|
|括号向量解析错误，法向量/方向向量的非零倍数被拒绝|按向量分量解析；对应题接受非零平行向量，拒绝零向量|
|全部独立答对仍出现统一的低证据反馈|依据实际作答建议迁移；其他状态分别提示核验或补习|

## 复现

在安装requirements-dev.txt的环境运行：

```bash
python tools/build_courses.py
python tools/validate_resources.py --update
python -m pytest -q
python -m compileall -q skill tools tests
python tools/build_delivery.py --output-dir /path/to/outputs
python tools/smoke_package.py --package /path/to/outputs/campus-gap-diagnoser-v0.1.1.zip
```

Skill结构检查另使用skill-creator的quick_validate.py。构建统计记录在[build-stats.json](build-stats.json)，逐主题覆盖见[coverage.md](coverage.md)。
