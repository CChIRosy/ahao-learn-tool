## 跨课程补习

- 钢柱稳定 → 材料力学压杆稳定、柔度与设计。
- 钢结构角焊缝 → 剪切应力和有效面积。
- 压弯构件 → 结构侧移与二阶效应。
- 水跃 → 水流动量、临界水深。
- 泥沙起动 → 明渠流、底切应力和摩阻流速。
- 波浪荷载 → 水流动量、波浪基础与结构作用。
- 回淤疏浚 → 泥沙守恒与航道高程。

数值答案相符时仍保留模型、单位及边界复核。对规范和经验系数，记录题给定义、适用条件及版本；题目给定系数服务该题计算。真实设计另需场址、现行适用标准和相应岩土地基模型。
